# Helve Library Mod for Dwarf Fortress

This is a mod for Dwarf fortress that adds a library with an raw registration framework for adding items without having to manually edit raws, hopefully making it less error prone and increasing modding compatibility. The library is currently in early development and only supports a few item types, but more will be added in the future.

Eventually, I hope to expand this library to support a complex registry of items, reactions, and entities that can be easily accessed and modified by other mods.
